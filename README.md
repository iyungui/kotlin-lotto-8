# 구현할 기능 목록

## 입력 기능
- [ ] 구입 금액을 입력받는다.
  - [ ] 1,000원 단위로 입력되는지 검증한다.
  - [ ] 1,000원으로 나누어 떨어지지 않으면 예외를 발생시킨다.
  - [ ] 숫자가 아닌 값이 입력되면 예외를 발생시킨다.
  - [ ] 0원 이하의 금액이 입력되면 예외를 발생시킨다.

- [ ] 당첨 번호를 입력받는다.
  - [ ] 쉼표(,)를 기준으로 6개의 숫자를 분리한다.
  - [ ] 각 번호가 1~45 범위의 숫자인지 검증한다.
  - [ ] 6개의 번호가 중복되지 않는지 검증한다.
  - [ ] 6개가 아닌 경우 예외를 발생시킨다.

- [ ] 보너스 번호를 입력받는다.
  - [ ] 1~45 범위의 숫자인지 검증한다.
  - [ ] 당첨 번호와 중복되지 않는지 검증한다.

## 로또 발행 기능
- [ ] 구입 금액에 따라 로또를 발행한다.
  - [ ] 1,000원당 1장의 로또를 발행한다.
  - [ ] 각 로또는 1~45 범위의 중복되지 않는 6개의 숫자를 가진다.
  - [ ] 로또 번호는 오름차순으로 정렬한다.

## 당첨 확인 기능
- [ ] 각 로또의 당첨 여부를 확인한다.
  - [ ] 당첨 번호와 일치하는 개수를 센다.
  - [ ] 보너스 번호 일치 여부를 확인한다.
  - [ ] 일치 개수에 따라 등수를 결정한다.
    - [ ] 6개 일치: 1등 (2,000,000,000원)
    - [ ] 5개 일치 + 보너스 일치: 2등 (30,000,000원)
    - [ ] 5개 일치: 3등 (1,500,000원)
    - [ ] 4개 일치: 4등 (50,000원)
    - [ ] 3개 일치: 5등 (5,000원)

## 결과 출력 기능
- [ ] 구매한 로또 수량을 출력한다.
- [ ] 구매한 로또 번호를 출력한다.
- [ ] 당첨 통계를 출력한다.
  - [ ] 각 등수별 당첨 개수를 출력한다.
- [ ] 수익률을 계산하여 출력한다.
  - [ ] (총 당첨 금액 / 구입 금액) * 100
  - [ ] 소수점 둘째 자리에서 반올림한다.

## 예외 처리
- [ ] 잘못된 입력 시 "[ERROR]"로 시작하는 메시지를 출력한다.
- [ ] 예외 발생 시 해당 부분부터 입력을 다시 받는다.
